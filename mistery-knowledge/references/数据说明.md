# 数据说明

默认 `references/index.jsonl` 每行一个 JSON 对象：

| 字段 | 含义 |
|---|---|
| id | 推文 ID，字符串 |
| author | 来源作者账号，不是摘要作者 |
| date / time_iso | 北京时间日期及带时区时间 |
| url | 原推链接 |
| topics | 关键词辅助主题标签 |
| text | 主题标签或整理者概括，非原文 |
| content_kind | source_index 或 editorial_summary |
| text_origin | 文字来源提示 |

精确 ID 查询不限作者；默认关键词查询限定 wr0789。公开版未收录其他作者背景正文。主题、摘要及 ID 参与关键词匹配；不支持自然语言语义召回。

用户自行准备的全文资料通过 `--data local_data/posts.jsonl` 读取，至少保留 id、author、date、time_iso、text 和 url。可选字段为 topics、in_reply_to、quoted_id。ID 必须为字符串；日期使用北京时间且时间带时区。全文的来源性质应在 text_origin 中说明。

`--data` 只在本机读取；脚本不上传数据。勿把个人全文资料放进 references/index.jsonl，也勿强制提交已忽略的 local_data 或 sources 目录。公开索引新增记录时，保留来源 URL，明确标注摘要作者，不把转述当作原文。
